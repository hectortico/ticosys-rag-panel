⚙️ Identificación del Cliente
¿Qué es? Un identificador corto, sin espacios ni caracteres especiales (usa _). Se usa como nombre del path del webhook y como clave interna del cliente en toda la plataforma.
Ejemplo: si el cliente es "Clínica Salud Norte", el slug sería clinica_salud_norte.
⚠️ Una vez creado NO se puede cambiar.

📧 Cuentas y Accesos
¿Qué es? El access token del agente bot ya existente en Chatwoot (ej: Tiko IA).
Dónde encontrarlo: Login como el bot en Chatwoot → Perfil → Access Token.
Para TicoSys: usar el token de "Tiko IA" (agent id=5).
¿Qué es? Recibirá acceso de administrador a la cuenta Chatwoot del cliente y los reportes diarios del sistema.
Dónde se configura: Chatwoot → Settings → Agents (se crea automáticamente).
Importante: debe ser un email válido al que el cliente tenga acceso.
¿Qué es? El email desde el que se enviarán confirmaciones de citas, recordatorios y seguimientos a los usuarios finales.
Dónde se usa: Gmail de TicoSys enviará "en nombre de" este email (o lo verás como remitente en los flows de n8n).
Si no tienes: usa el mismo que el email de contacto del cliente.
¿Qué es? El ID del calendario de Google donde el bot agendará las citas de los usuarios.
Cómo encontrarlo: Google Calendar → Configuración del calendario → "ID de Calendario" (al final de la sección de integración).
Si es el calendario principal: usa simplemente primary.
🔑 Credenciales de API
¿Qué es? Token JWT para que el installer pueda crear y activar workflows via la API de n8n.
Cómo obtener uno nuevo: ir a n8n.ticosys.com → Settings → API → Create API Key → copiar el token generado.
Si lo dejas vacío: se usará la clave guardada internamente (puede estar expirada).
